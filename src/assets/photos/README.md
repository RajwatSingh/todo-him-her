# picture of the day

Drop image files straight into this folder — `.jpg`, `.jpeg`, `.png`, `.webp`
or `.avif`, upper or lower case. Nothing else needs changing: the app picks
them up on the next build.

One photo is shown per day. Every picture appears once before any of them
comes round again, and the order is reshuffled each time the deck runs out.
The choice is worked out from the date, so both of you see the same picture
on the same day without anything being stored.

While the folder is empty the section simply doesn't render.
